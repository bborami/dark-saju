# 🌙 어둠의 사주 · 냥선생의 독설 만세력

생년월일(시)을 넣으면 만세력 4기둥을 뽑고, 냥선생이 독설로 풀이해 주는 웹앱입니다.

👉 https://bborami.github.io/dark-saju/

- 만세력: 양력·한국시간 기준, 절기(태양 황경)로 년주·월주 계산, 시간 모르면 시주 생략
- 풀이: 종합(60갑자 일주별) / 관계 / 연애 / 돈 / 직업 / 자기합리화 / 올해 경고 / 냥선생의 한마디
- 단일 HTML, 외부 라이브러리 없음 (Google Fonts만 사용)

재미로 보는 독설 풀이입니다. 진지하게 받아들이면 그게 제일 아픈 부분.
